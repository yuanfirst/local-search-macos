# 本地搜索

双击「本地搜索.app」打开。当前构建适用于这台 Apple Silicon Mac，无第三方运行依赖。

应用图标是蓝色背景的白色放大镜，适合在 Finder 和 Dock 中识别。

1. 选择要搜索的文件夹，也可以直接粘贴完整路径；留空时搜索整机（从 `/` 开始），仅能读取当前账号有权限访问的文件。
2. 按文件名搜索：在「文件名包含」中输入关键词，如 `报告` 或 `.txt`。
3. 按内容搜索：在「文本内容包含」中输入 `tsl76.vfoo.cc:47810`。
4. 点击「开始搜索」。两项都填时，文件必须同时满足两项条件。
5. 选中结果，点击「打开」或「在 Finder 中显示」。

搜索递归包含所选文件夹及所有子目录、隐藏文件和应用包内文件。匹配区分大小写，点号与冒号均按普通字符处理。搜索只读取文件，不修改文件内容。点击「停止」后保留已发现结果，并提示结果不完整。

内容搜索支持 UTF-8、GB18030（兼容常见 GBK 文本）、带 BOM 的 UTF-16 文本，分块读取，无文件大小上限。不解析 Word、PDF、压缩包或图片。无 BOM 的 UTF-16、UTF-32 和其他编码可能无法匹配。二进制检测以开头的空字节为依据，是启发式判断；结果请结合文件类型确认。

不跟随符号链接，避免循环或搜索到指定目录之外。无权限或读取失败的路径显示在「查看异常」中。系统隐私目录需要 macOS 授权；云端尚未下载的文件由系统决定是否下载或返回读取错误。

## 从源码构建

需要 Apple Command Line Tools（提供 Swift 编译器），运行：

```sh
zsh build.command
```

## 验证

```sh
swiftc -parse-as-library Search.swift Tests.swift -o /tmp/local-search-tests
/tmp/local-search-tests
```

测试使用独立临时目录，覆盖子目录、中文文件名、跨读取块匹配、字面字符串、UTF-16、组合条件、取消与链接循环。
